# Synthesis v1.3 — Research Verification Checklist

**A practical checklist for authors, reviewers, editors and researchers.** This is a methodological framework, not a separately trained AI model. It can be used manually without programming.

## Choose your approach

- **[Open the human-readable checklist](SYNTHESIS-HUMAN-CHECKLIST.md)** — work through each check, recording the source and evidence.
- **[Copy the optional AI-assisted checking prompt](SYNTHESIS-COPY-PASTE-AI-PROMPT.md)** — use only with material you have permission to process.
- **[Complete the participant-count worksheet](SYNTHESIS-PARTICIPANT-WORKSHEET.md)** — establish populations and exclusions before comparing totals.
- **[Follow three worked public examples](SYNTHESIS-WORKED-EXAMPLES.md)** — distinguish a historical correction, an explained difference and a limit on reproduction.
- **[Read the methods and evidence guide](SYNTHESIS-METHODS.md)** — detailed records, software boundaries and evaluation requirements.
- **[Use the checklist in the research harness](SYNTHESIS-HARNESS-PILOT.md)** — source-replayed development records, saved evidence, correction history and the independent evaluation runbook.

## What does Synthesis check?

Synthesis organises established checks for numerical consistency, denominators, units, confidence intervals, statistical methods, endpoint and population comparability, consistency between manuscript sections and source documents, and special issues in systematic reviews, meta-analyses and network meta-analyses.

The reviewer must investigate alternative explanations for an apparent discrepancy, including rounding, different models, estimands, populations or document versions. A failed check is not automatically a confirmed error. Insufficient evidence requires abstention.

**Review safeguards updated 6 November 2026:** The checklist and optional prompt now require exact-quotation checks, saved calculation evidence and point-by-point source rechecks of replies. See [reviewing explanations and preventing false positives](SYNTHESIS-RESPONSE-REVIEW.md). A disagreement alone does not refute a concern; an acknowledgement of one point does not validate an entire enquiry.

**Routine use:** Start with six core checks, apply the relevant detailed checks, and repeat the revision sweep after changes and before submission. Record Pass, Review needed, Insufficient evidence or N/A with a reason. Keep issue class and demonstrated impact separate. These documentation changes do not add automated count extraction or establish an accuracy improvement.

## Validation status

The accompanying implementation has undergone synthetic software tests. Independent prospective validation of real-world detection accuracy has **not** been completed. A completed checklist does not certify that a paper is correct.

## Responsible use

Access and processing of each source must be authorised for the intended purpose. Respect copyright, publisher terms, text-mining restrictions, confidentiality, privacy, research-ethics requirements and no-contact requests. AI assistance does not override these obligations. Do not automatically contact authors or editors or make allegations based on unchecked flags.

Use the checklist and prompt above to apply the procedure. Keep manuscript-specific evidence and correspondence in an authorised private record.
